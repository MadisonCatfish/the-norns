[ FLEET DOCTRINE TELEMETRY ]

Engineered for nullsec krabbing & Havens.

Replace guesswork with real-time mathematical telemetry. Track individual gunboat efficiency, instant capital alarms, and wallet bounties in the heat of combat.

01 · COMPETITION & DPS RACELIVE ANIMATION

Frigate Runner & Lightning Rod Live ECG

In Competition mode the Thunderchilds shoot a frigate runner, and their Vorton shots arc on to the NPCs. The Lightning rod graph shows the damage the runner takes per second against its repair, and the Vorton panel shows each ship's throughput.

02 · CAPITAL GRID ALARM

Molten Hull Heating & Audio Sirens

The second an NPC Dreadnought (Guristas, Blood, Sansha, Serpentis, Domination) lands on grid, the hull glows in amber. An NPC Titan turns the hull crimson. The three-pulse sound is off by default; turn it on in Settings → General.

03 · DUAL DOCTRINE METERS

Vorton Projector & Smartbomb Cycle Progress

Vorton damage per ship on one panel, and smartbomb cycle progress on the other. With the Thundpack filter on, hits on your anchor battleship (Nestor) are left out, so the numbers count damage to NPCs.

04 · SESSION HISTORY & CALENDAR

Session History & Interactive Calendar Ledger

Every session is saved on your PC in %LOCALAPPDATA%\The Norns, and updates keep it. The list shows each site's ISK and anomaly count, faction commanders (★), titans and pirate dreadnoughts. The calendar card switches between Today, Quarter, Year and All sessions.

05 · COMPACT OVERLAY

Compact Mode for Single Screens

Compact mode, set in Settings: no power display or printed band, a narrow damage display and a shorter Close key. The bounty grid stays as one row of column averages.

06 · POTATO GRAPHICS

Potato Mode for Large Client Counts

Off by default; turn it on in Settings. Renders at 5 FPS with no glow, glass light or animation. Measured at ~3.5% of one CPU core on the owner's rig, against 28.5% without it.

[ CCP POLICY NOTE ]

Read-only data pipeline.

How The Norns gets real-time telemetry: it reads the logs the client already writes. We are not affiliated with CCP and cannot promise how CCP treats third-party tools.

[ 01 ] LOCAL GAMELOGS

Non-Locking Text Tailing

Reads standard text logs generated by the client in Documents\EVE\logs\Gamelogs using FileShare.ReadWrite. Never locks or alters the file stream.

[ 02 ] MEMORY BARRIER

Zero Process Injection

Completely isolated from exefile.exe. No DLL injection, no memory scraping, no network packet sniffing. The optional Carousel module (off by default) uses a window-focus hook and can bring a client window to the front.

[ 03 ] PASSIVE HUD

No Input Broadcasting

We designed it around CCP's 1-action-1-input guideline. It displays telemetry only and sends no clicks, keystrokes or broadcasts.

[ FAQ ]

Questions about The Norns.

Which Windows versions does it run on?

Windows 10 and 11. It needs .NET Framework 4.8, which Windows 10 and 11 already include.

Does it need a server or an account?

No. It runs locally, with no account and no server component. The only network request is the optional update check.

What does the update check send?

It asks GitHub for the latest release version. It sends no information about you or your game clients, beyond the normal request to GitHub's API.

How do I turn the update check off?

Settings -> General, or the "Check for updates at start" switch in the installer.

Does it send keystrokes or clicks to the game?

No. The optional Carousel module (off by default) can bring a client window to the front and switch between clients with hotkeys. Nothing else sends input.

Does it read game memory or inject code?

No. It reads the text logs in Documents\EVE\logs\Gamelogs and the titles of the EVE windows. It does not inject DLLs or read process memory.

Where are my settings and session data kept?

In %LOCALAPPDATA%\The Norns. Installing or updating the app keeps them.

Is it allowed on the official servers?

The app does not connect to any server. We cannot promise how CCP treats third-party tools, so read CCP's current policies before you use any tool.

Is it affiliated with CCP?

No. The Norns is a free, open-source, fan-made tool under the MIT license.

Can I see the source code?

Yes. Source code and build guides are openly available.

Which languages does it support?

English, Ukrainian, Spanish, German, Italian, French and Chinese (Simplified). Settings -> General switches the language.
