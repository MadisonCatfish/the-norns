[ 01 / CCP FAIR PLAY COMPLIANCE ]

Architected to stay out of the game client.

Every architectural boundary in The Norns is designed to ensure zero interference with the game client, zero network leakage, and absolute peace of mind for multi-billion ISK setups.

[ I/O ISOLATION ]✓ READ-ONLY

Read-Only Gamelog Streaming

The Norns reads solely from standard plain-text logs written by EVE Online in Documents\EVE\logs\Gamelogs and OS window titles using non-locking FileShare.ReadWrite handles.

new FileStream(path, FileMode.Open, FileAccess.Read, FileShare.ReadWrite)
[ PROCESS BARRIER ]✓ ZERO INJECTION

Zero Memory or Process Hooks

The Norns never calls OpenProcess with VM access, never inspects or alters exefile.exe virtual memory, and injects zero DLLs. It is completely isolated in its own userland process.

VirtualAllocEx / WriteProcessMemory / CreateRemoteThread: NOT LINKED
[ INPUT INTEGRITY ]✓ PASSIVE TELEMETRY

Zero Input Broadcasting

No simulated keystrokes, no clicks, and no input broadcasting. The optional Carousel module (off by default) can activate a client window. The telemetry display is passive; the design follows CCP's 1-action-1-input guideline.

SendInput / keybd_event / mouse_event: NOT PRESENT
[ PRIVACY GUARANTEE ]✓ LOCAL FIRST

No Silent Telemetry or Beacons

No accounts, no user analytics, no tracking beacons. The only outbound network call is the transparent, toggleable startup check against GitHub Releases API for software updates.

api.github.com/repos/MadisonCatfish/the-norns/releases/latest (Toggleable)

[ 03 / REPRODUCIBLE BUILDS ]

Build your own binary.

The Norns compiles using native Windows developer tools (.NET Framework 4.8 via Roslyn). No Node.js, Python, or external package managers required for compilation.

Windows PowerShell · C:\The Norns>
POWERSHELL 5.1+
# 1. Clone the repository
git clone https://github.com/MadisonCatfish/the-norns.git cd the-norns
# 2. Build the application binary (TheNorns.exe)
powershell -ExecutionPolicy Bypass -File native\build.ps1 -Out bin
# 3. Package the setup installer and portable zip
powershell -ExecutionPolicy Bypass -File native\build.ps1 -Out release -Setup
# 4. Run automated self-tests
bin\TheNorns.exe --selftest-dps selftest_output
