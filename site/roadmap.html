16 · Updates in one click

1.5.0

The app downloads and installs a newer release itself. The version plate blinks; a click shows "1.x.x is available — Update"; the rest goes on its own. Settings → General: "Install updates automatically" (off by default). Works from the version that brings it on (1.1–1.3 update by hand once). After SignPath signing: a self-updating unsigned exe looks like a downloader to antivirus heuristics.

  • ✓The version plate blinks when a newer release is out (as now)
  • ✓A click on it shows "1.x.x is available — Update"
  • ✓"Update": the app downloads the installer from GitHub Releases itself (no browser), checks its SHA-256 (after signing also the signature), closes, installs the new version over the old one quietly (no admin rights, settings kept) and starts again
  • ✓Settings → General: "Install updates automatically", off by default (on: the same without the click, never in the middle of a site)
  • ✓Installer: a quiet mode (no pages, same folder and shortcuts)
  • ✓Privacy texts (README, installer, settings): the download described, with its switch
  • ✓Sketch → owner's OK → code → release
